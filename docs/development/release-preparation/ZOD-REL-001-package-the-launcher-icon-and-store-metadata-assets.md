## Description

Finalize the platform-specific launcher-icon exports and any store-listing image assets derived from the already-designed logo.

## Implementation Details

- Generate the full iOS/Android launcher icon size set from `assets/zodiann-logo.svg` ([ZOD-FND-008](../foundations-architecture/ZOD-FND-008-package-and-integrate-the-app-icon-logo-asset-set.md)'s source asset).
- No new visual design is created here — this is packaging work only.

## Notes

- **From ZOD-FND-008:** the full Android and iOS launcher icon set already exists and is generated by `tool/launcher/gen_launcher_icons.dart` (Android adaptive + legacy, iOS 15 full-bleed opaque files; `melos run launcher:check`). This task narrows to what FND-008 left out: the Play Store 512 px listing icon, the feature graphic and other store-listing assets, running each store's validation tooling (Xcode / App Store Connect, Play Console; the iOS on-device check is outstanding), and any themed (Android 13 monochrome) or iOS 18 dark / tinted icon variants. Reuse the generator rather than hand-exporting.

- **iOS split (2026-11-24, owner decision):** the iOS validation (Xcode, App Store Connect) and the iOS 18 dark and tinted variants moved to [ZOD-IOS-004](../ios/tasks/ZOD-IOS-004-verify-the-launcher-icon-set-in-xcode-and-app-store-connect.md).
